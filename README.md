# memoryfield spec

This repo contains the RFC-style specification for the "memoryfield" AI agent
memory format.

memoryfields are a vastly simpler way of giving AI agents memories.  The
memoryfield format is based on standard file formats with wide support that
both LLM agents and humans can easily understand.

For an introduction to the format, please read [Agent memory as a file
format](https://calpaterson.com/memoryfields.html).

For the RFC-style specification, see [SPEC.md](SPEC.md).

And, for the Agent Skill implementation, see the repo
[calpaterson/memoryfield-skill](https://github.com/calpaterson/memoryfield-skill).
